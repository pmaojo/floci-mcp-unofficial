for agents.

An MCP server that lets an AI agent inspect and provision your local AWS, Azure, GCP and OCI. Tools below are the real ones the server registers. Recipes are the Docker stacks it can start for you.

Unofficial community project. Not affiliated with or endorsed by the Floci project. Floci does the emulation; this server only talks to it. Support floci-io/floci.

skills

Skills first.

The tools are the hands. Skills are the playbook: short instructions an agent loads on demand that say which tools to call, in what order, and when to stop and ask. Install them and the agent stops guessing.

install as a Claude Code plugin 
/plugin marketplace add pmaojo/floci-mcp-unofficial
/plugin install floci@floci-mcp-unofficial
or just the skills 
mkdir -p ~/.claude/skills
ln -s "$PWD"/skills/* ~/.claude/skills/      # or cp -R skills/* ~/.claude/skills/

A skill that needs a toolset which is not enabled by default says so. Ask for it with FLOCI_TOOLSETS and restart the server.

install

Three commands.

git clone https://github.com/pmaojo/floci-mcp-unofficial
cd floci-mcp-unofficial
uv sync && uv run python floci_mcp.py

Needs Python 3.10+, uv and a running Floci. Docker for recipes. By default it registers the default toolsets only; set FLOCI_TOOLSETS=all for everything, or FLOCI_READ_ONLY=1 to drop every tool that writes.

toolsets

Not all 138 at once.

A client sends every tool definition on every conversation, and models pick worse among many similar tools. Only the enabled toolsets are registered.

toolsettoolsdefault
FLOCI_TOOLSETS=core,storage    # only these
FLOCI_TOOLSETS=all             # everything
FLOCI_READ_ONLY=1              # drop every tool that writes
FLOCI_TOOLSETS_ALLOWED=ops     # optional cap; unset: the agent may enable any

safety

It can change your machine.

  • 60 tools write. FLOCI_READ_ONLY=1 removes them; annotations let a client confirm first.
  • Cloud secret tools return names, never values. get_secret_value (AWS) does return the value.
  • run_local_aws_cmd is full aws CLI access: a command can pass its own --endpoint-url.
  • proxy_http_request requests any URL from the host.
  • Tool descriptions steer the model. list_toolsets returns a SHA-256 of every registered definition: pin it and compare after updates.
  • Hybrid tools can use real AWS credentials. They live in hybrid, off at the start, but an agent may enable it unless you cap it with FLOCI_TOOLSETS_ALLOWED.
  • The marketplace starts containers on your Docker. Teardown removes their volumes.

Azure, GCP and OCI tools cover storage, messaging and secrets. AWS keeps the full surface.

Secret tools return names, never values. Tools marked WRITE change the local emulator or your Docker.
